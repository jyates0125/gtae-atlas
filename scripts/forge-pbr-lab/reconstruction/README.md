# Elario Forge reference-fit research pipeline (v1)
Original Elario synthetic road-body envelope only. No Rockstar media, third-party model or game identity is embedded. This is a numerical experiment, not an accepted showroom asset.
1. `node scripts/forge-pbr-lab/reconstruction/test-fit.mjs`
2. `node scripts/forge-pbr-lab/reconstruction/run.mjs` writes a candidate, reference SHA-256, measured baseline, full improving history and stop reason to excluded qa-evidence.
3. Optional local Blender: `blender --background --factory-startup --python scripts/forge-pbr-lab/reconstruction/blender_export.py`. Blender exports a single material-bearing envelope GLB; it is not a complete vehicle. Audit with the existing `audit_glb.py`.
4. For future measured references: record source/license/revision, orthographic or calibrated camera, uncertainty and multiple independent views. Separate fitting targets from held-out validation. Review identity, rights, realistic topology, parts, PBR, mobile/desktop, owner visual acceptance and release policy. No candidate may promote itself. Real-reference intake is intentionally disabled in v1.
The fit loop reconstructs closed elliptical section rings from three per-station silhouette measurements (width/top/bottom), assesses generated mesh vertices, and accepts only lower RMS error with a maximum of 32 iterations. The target and score are synthetic and do not measure photorealism or GTA likeness. No web or AI calls, no automatic source retrieval, no public renderer or save changes. Future stages include dense section sampling, contour curves, held-out views, wheel arches and component meshes.
