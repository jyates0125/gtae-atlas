3D terrain · research / user import

GTADB.ORG reconstructed GTA VI elevation methodology

GTADB elevation reuse: GTADB FAQ welcomes website-material reuse unless otherwise stated, and its experimental Elevation API documents per-point ground-height queries. Atlas uses those published methods and allows user-initiated single-coordinate checks without collecting or publishing a complete GTADB heightfield. The bulk GTA VI elevation binary is not included in the published GitHub data snapshot; no claim of certified or official geometry is made.

Atlas's 3D renderer follows the published GTADB map coordinate and elevation decoding conventions, but the GTADB elevation binary is not bundled in this release. GTADB's FAQ invites reuse unless otherwise stated and explains that its GTA VI elevation is a community reconstruction, not a perfect game survey. Atlas accepts a personal local heightfield for a clearly unverified research preview, with optional SHA-256 and claimed alignment checks; an imported file is not a public data distribution or independent source certification. We credit GTADB.ORG, rolux and contributing mappers for published methods and map research, while Team Jura owns its original viewer and validation code. A separate 16-bit Leonida GIS raster is also a research candidate, not a redistributed Atlas asset.
