What you're looking at

The Forge uses original sculpted WebGL geometry: selected models have distinct model-targeted proportion studies; others use class-based concepts. It is an original concept, not an exact production game mesh. Selecting a named GTA vehicle changes the reference image and the design workspace, and may select an original model-targeted study, never a Rockstar or GTADB game mesh. The 3D idea is a paint/rotation concept tool, and available GTA V images are credited reference material. GTA VI references link to Rockstar’s official gallery; an Elario illustration is not an exact vehicle photograph.

Current customization coverage

Our original viewer supports 3D rotation, zoom, original model-targeted and class-specific concepts, camera presets, surface finishes, accents, lighting, road stance, aero or deck styling, and four selectable original display environments. The chosen showroom environment is stored with a saved concept or named build; older designs default to an automatic class-specific stage. It is not an in-game property. Per-model wheel meshes, liveries, spoilers, true Rockstar assets and precise modification catalogs are not available in this original concept tool. Those need separately licensed model files and verified metadata before they can be represented faithfully.
