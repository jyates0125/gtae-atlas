# Atlas 23.8 San Andreas tag dataset

100 numerical game-world tag object placements, attributed to Prineside DevTools / therainycat. The original site (https://dev.prineside.com/en/) requests a source link when copying materials; the preserved tools at https://solsroleplay.com/dev/ likewise request credit. The numerical positions were retrieved from the attributed transcription at https://github.com/jakubfalenczyk/gtasa-map/blob/55ddc3fb557ddbf476b72b5e6b1d8db77cbaf732/data/tags.json. No guide descriptions, screenshot images, maps, or derivative source code were copied. 61 coordinates (model 1490, 1524, 1525 and 1530) exactly matched original Prineside published exports in this audit; the other 39 are transcription-only because original pages could not be retrieved. No individual gameplay or pixel-perfect alignment claim. All 100 positions have distinct triples, valid world bounds and source model counts. Existing 150 pickups unchanged; new tag route sets separate. Atlas numbering follows model/listing order, not official guide order; existing checklist entries remain but prior numbering must be checked. Stunt jumps remain tracking-only. Source rights do not transfer Rockstar IP.
