## Review loop and evidence record
Every completed batch records date, lane, previous baseline SHA, exact candidate SHA, owner/user problem, before/after measurable evidence, affected dependencies, tests run and results, reused evidence and equivalence rationale, unresolved failures, release status, rollback and next executable task. Update latest handoff and this queue; use the capability register for substantial improvements. A missing test, incomplete mapping or unavailable browser is an open issue, not a pass. A repeated complaint requires a durable regression and shared-cause analysis, not another isolated CSS patch.
Track player-task success (direct game-to-feature links, correct scope and back path), clicks/required manual inputs, duplicate destinations, overflow/occlusion, footer geometry, data freshness and coverage, and actual test time. Baselines not measured yet are marked unknown. No arbitrary numerical targets presented as already achieved. Audit all 81 root paths and query variants; compare actual route evidence, not just HTTP success. Preserve site-wide user accessibility and legally required attribution.
