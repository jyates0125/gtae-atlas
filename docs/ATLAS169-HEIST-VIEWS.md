# Atlas 16.9 — heist view system and pin-art policy

The owner approved the premium heist cover art, distinct focused mission maps and saved route/POI behavior. This release adds per-heist map/detail/route tabs, safer original icon treatment and links between guides and highlighted POIs. All old guest-data keys and existing approved raster assets remain intact.

- **Enhanced map (15/15):** current cinematic original site-map background with colored, selectable, custom HTML/CSS pointed pins and optional saved route. The pins are Elario-authored; we did not copy Rockstar or third-party proprietary icon assets because a specific reusable license was not established.
- **Objective detail (15/15):** named mission POI cards with category badge, clickable return-to-map/highlight and cinematic mission-context reference. The mission scene is explicitly illustrative, not an in-game interior floor plan or a claimed current loot location. Diamond Casino labels this a Vault & objectives view; Kortz is Museum & objectives; Cayo is Compound & objectives. A full accurate interior map is still pending source verification or a newly created dedicated conceptual detail asset.
- **Route planning (15/15):** existing 16.7 selectable schematic map, source-truth notice and locally saved route/list; no false claim of precise drivable paths.
- **Original island explorer (Cayo only):** existing original Cayo island view and its independent schematic planner, embedded only on user click, with open-full-size link. The sourced image's coordinate transform has not been calibrated to our 16.7 schematic POIs: no falsely overlaid map pins. Do not copy this third-party image into our proprietary asset directory absent reuse rights or an appropriate rights basis.
- **Linked controls:** a 16.8 guide's Show related POI returns users to Enhanced map and selects a matching available point. This uses only existing DOM interactions and does not change saved checklists, notes, awards or routes.

Future: get user-captured or rights-cleared in-game map snapshots; document image provenance and coordinate registration for real pins. Create dedicated high-resolution interior image assets (casino vault, Kortz galleries, Cayo compound, Humane lab) whose positions are clearly conceptual until matched. Map views should never misrepresent uncertain or rotating loot spawns.
