## Reference comparison

- GTAWeb.eu: game-specific map category toggles, routes, own status/date flags; consult only for functional behavior, not copyrighted data reuse.
- GTADB.net: marker/category counts, daily rotation status, vehicle galleries; public availability does not imply redistribution license.
- GTADB.ORG: explicitly published MIT code and CC BY 4.0 landmarks/media/tiles; implementation uses attributed data license only for locally mirrored landmark records.
- GTAMI: per-source terms rather than unrestricted copying. Third-party official Rockstar art is not automatically public domain.
