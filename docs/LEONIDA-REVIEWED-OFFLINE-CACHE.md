# Reviewed Leonida offline snapshot boundary
The previous main could recover a raw pre-review VI cache on snapshot fetch failure, allowing held coordinates back into the map. This isolated candidate skips old VI starter and raw upstream cache, uses a separate revision-specific reviewed cache containing the entire attributed snapshot, validates schema, reviewed metadata, row counts, coordinate bounds and held IDs before use, and reports unavailable offline if no reviewed copy exists. No deletion of old caches, personal progress, imported packs, tiles, V/Online records, or changes to other worlds. The browser guard compares the recorded source hash field and structure; actual source bytes are independently hashed by existing CI, not cryptographically authenticated in browser. Future reviewed revisions must update the pinned review contract with the manifest. Independent source ledger and research workspace not changed. Tests simulate an old raw cache, blocked local snapshot and successful reviewed cache recovery. No claim of gameplay coordinate accuracy or universal offline coverage.
