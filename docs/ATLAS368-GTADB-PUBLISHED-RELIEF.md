# Atlas 36.8 — GTADB-source approximate 3D is now a real implementation

Owner instruction: be creative with approximate evidence; use GTADB and its contributors; do not invent official accuracy. GTADB map tile and landmark reuse is settled under its CC BY 4.0 repository data license. The source coordinate convention and atlas engine remain aligned with GTADB.

- Same author rolux's published gtamaplib numerical mapping table at 73b847330b6741b0214515178829d0335249df07, blob bd3f7f50e8548a74ff8394011693d425fedf8b45, contains 1,243 uniquely named triangulated XYZ landmark records and camera/player mapping observations. It includes actual ground-like observations rather than only X/Y. The toolkit LICENSE dedicates its software to the public domain. Credit rolux, GTADB and contributors; use numeric mapping facts, no source photos or cameras' imagery.
- Actual source build [run 45296521287](https://github.com/jyates0125/gtae-atlas/actions/runs/45296521287) used **286 selected observations**: 60 ground landmarks, 31 labeled player-ground proxies, 162 sea-level coastline/waterline records, 33 inland-water-edge points. Source selection is conservative and excludes roofs, towers, skyscrapers, and arbitrary camera altitude. 194 125m bins, 74 ground/ground-proxy/inland bins.
- Reconstruct 96x110, 10,560 cells, same GTADB bounds. Inverse-distance 8-neighbor smoothing, 125m clustering, coast taper, GTADB YANIS v18 palette-derived connected ocean mask from 16 immutable GitHub tiles, and confidence fade. The output covers 7,376 approximate ocean cells, 973 sparse land cells, 1,415 intermediate land cells, 796 near-source land cells. A 192–194m lattice is a **coarse illustrative approximation**, not the missing 12m-scale dense dataset. 271.9m rendered maximum. Same-source spatial-bin leave-one-out median 0.74m, P90 15.69m, maximum 262.79m; these are internal interpolation residuals, **not independent game accuracy**. Large mountain errors are a real limitation. No speculation about exact underwater depth, buildings, game geometry, navigation or elevation in unobserved areas.
- Source-derived committed JSON SHA-256 of exact compact JSON excluding terminal newline: cfb8f5197b52250e2f0251d0252d711392db60ad9364ac1c57a2c6bc9883daaa. The SHA is checked by the regression. No external runtime data calls; only local static derived data.

## Functionality
The old 3D button checks a local dense heightfield first. Without it, the illustrated 2D/perspective map remains usable and presents **Approximate 3D**. A deliberate tap loads the bundled 44 KB JSON in the same browser, activates the original WebGL terrain with a separately scoped approximate surface, and shows a persistent **3D · Approx.** label. Coverage toggle shades near, intermediate, sparse and approximate ocean areas; this is distance to source observations, not a probability of accuracy. The surface never sets hasElevation() and cannot pass the dense DEM release audit or local evidence comparison. Exact local dense import takes precedence over approximate mode and clears its overlay; return to 2D clears the approximation from the renderer; validated JSON is reused in the page session. Existing markers, routes and private saves remain intact. No real DEM or synthetic dense test data are deployed.

## Research and official view handoff
The dense lookup finishes before the approximate option can be selected, so a delayed compatible dense grid cannot be discarded by a competing approximate tap. Private local import always wins. The selected 2D/3D buttons expose their pressed state to assistive technology. Opening the Rockstar official poster cancels pending or active research terrain and returns the interactive map to 2D, preserving its selected research layer and user notes. GTADB Scaly/YANIS remains the default; the credited DUPZOR V51/Loki is retained as an optional separate community comparison. The official poster remains an independent reference, never a terrain texture. The credits include the immutable relief-profile link and clearly identify it as a reference, not a DEM. The browser test now includes the official-to-research round trip and retained optional DUPZOR selector.
