# Atlas 13.0 — Public Preview + Community Growth Release
**Prepared from:** development fc4c2b4 (November 18, 2026)
**Release safety:** Single owner-approved merge to Cloudflare-connected development after Chromium, Edge and validated ZIP checks. Then subsequent work moves to independent review branches; protected main unchanged.

## What changes
- Home (`index.html`) is a premium cinematic **public welcome/launch page**, with original approved Elario artwork, source-disclosed scope, and a visible share button.
- Former complete homepage is preserved as `atlas-dashboard.html`, linked via **Enter Atlas**. Existing world selector, 13 worlds, native map destinations, personal browser save keys, heists, garage and research are unchanged.
- `atlas-share.html` is a real launch toolkit for Facebook, TikTok, Instagram, Discord, Reddit and X. User-initiated share sheets, platform share links and caption copying work without connected social accounts. No fabricated profile or Discord invite.
- Film's `one-last-ride.html` gains film-specific Open Graph metadata, friend-sharing and clearly marked unfinished film production stages. All nine chapter scenes, local/private memory wall, character notes and real MP4 preview are preserved.
- `robots.txt` and `sitemap.xml` list intended public entry points for search-engine discovery. Search engine indexing, sharing reach and any social feed distribution cannot be guaranteed.
- Privacy: Share links only use an optional `from=platform` label to distinguish user-selected links; the site stores **no** social engagement or conversion records and has no pixel, email collection or user tracking backend.
- **Artwork difference:** The independently generated high-resolution Facebook promotional poster was supplied to the owner in chat but its binary is not yet in GitHub; the actual public page uses the already approved, locally bundled `art/atlas98-approved-hero.webp`. This is a known visual-parity gap. The original poster should be uploaded with an authorized asset-transfer step later, then independently verified at full resolution. Do not claim the image file was shipped.

## How the owner can put it in front of people
1. Launch Facebook post already published; pin an updated post with the welcome-page URL if desired. Post the original promotional image directly when Facebook's preview thumbnail is stale.
2. TikTok: original short screen demo of a working map, collection or route, with a real community question. Paste the prepared caption and link into bio or other supported profile feature.
3. Instagram: original Reel or carousel with project artwork and product demo; link in bio/story where supported. Do not present speculative VI coordinates as confirmed.
4. Discord: invite only on channels whose moderation rules allow it. Supply the official Community Server invitation URL later if one is created and approved.
5. Reddit/X: provide substantive useful context, follow moderation rules; avoid repeated cross-posts. Consider a clear top-of-profile explanation of project scope.
6. Keep a simple manual log of post date, platform, clip/topic, opens, saves, comments and actual feedback. Social algorithms weigh real viewer behavior; there is no guaranteed enrollment or shortcut.
7. Submit the new sitemap via verified search engine webmaster accounts if desired; domain ownership remains with the owner.
