# Atlas 16.7 — 15 heist-specific maps and research scope

- **Rendering:** Each mission gets an original mission-specific WebP aerial **concept map**, real interactive filters, accessible pins, zoom/Fit and optional pan, route sequencing and local-only scoped/checklist/award tracking. Its cinematic approved cover art is unchanged. Sixteen raster concepts are included; the extra HQ overview asset is reserved for future use.
- **Provenance:** Aerial images are original Elario Studios AI-assisted fan concepts. They are *not* copied Rockstar maps, gameplay captures, accurate building footprints, satellite imagery or actual game-space coordinates. Canvas overlay coordinates are **illustrative diagram positions only**. Every mission presents a source link; screenshots are not claimed to georeference markers.
- **Cayo:** The mission first shows a focused custom map and links to the existing `atlas-cayo.html` original game-island image tab and a separate interactive schematic view. Existing local `data/cayo-schematic.json` contributes extra source-named approximate POIs; daily chests/spawns are not rendered as today's actual position. Source: https://www.rockstargames.com/gta-online/heists/cayo-perico-heist and https://www.gtabase.com/gta-online/jobs/heists/the-cayo-perico-heist.
- **Casino:** A casino site *concept* illustrates access categories and vault scouting; it does not purport to be a real casino floor plan. Source: https://www.gtabase.com/gta-online/jobs/heists/the-diamond-casino-heist.
- **Prison, Humane, Fleeca, Series A, Pacific Standard, Cluckin' Bell, Salvage, Auto Shop, Agency and Kortz:** Dedicated sites or multi-mission planning diagrams; challenge and POI locations are not passed off as true map positions. Each needs source calibration/legally usable official basemaps before verified positional parity.
- **Doomsday I–III:** Regional mission concept first; existing full GTA Online map kept as secondary route planning.
- **Challenges:** GTA Online Career Progress categories may have four tiers, but these are shared progress groupings, not invented exact per-mission conditions. Cayo Elite criteria are listed from GTABase and manually tracked; all other non-sourced challenge slots are clearly personal goals. Login/sync remains disabled.
- **Save integrity:** Existing `teamjura-heist-<id>` checklists and `teamjura-heist-plan-v1:<id>` notes are unchanged. New schematic progress uses `teamjura-heist-focus-v1:<id>` only. Manual export is available via pre-existing local plan tools.
- **Still required for full parity:** Source-calibrated actual positions for POIs on the original map, in-game menu exact tier requirements, multi-floor casino/museum interior geometry, route permissions and rights for third-party game imagery, deeper mobile/device tests, and exact Cayo treasure chest daily positions.
- **Release:** This is staging PR #70, **not a release**. Keep no live merge before owner review of this new version, Chromium + Edge + validated ZIP and desktop/mobile visual evidence.
