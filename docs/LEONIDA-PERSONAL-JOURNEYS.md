# Player-specific Leonida journeys
Owner direction Nov 28: gameplay can vary by decisions, chapter, character, optional scenes and ending. Never assume variation exists for a particular mission without evidence. The first implementation is a local journal, not a sourced mission graph. Users set their own chapter/stage, character, goals, choices/notes. Each profile has an immutable UUID and its own fields. Notes hidden at initial load and after switching or saving; this is visual spoiler control, not encryption or access security. Existing VI counts and Discovery marks remain independent; this batch does not silently migrate them or imply profile-specific completion. No game connection, telemetry or auth. Backup merges new profiles and keeps local versions on conflicts; raw corrupt bytes recoverable. Web Locks where available, pre-write comparison best effort otherwise; simultaneous edits to the same profile still require further revision/conflict UX. No destructive reset/delete. Future chapter guide must add sourced prerequisites, opt-in spoiler layers, explicit optional/missable/replay status and mutually exclusive paths only when documented. No fake mission names, exact ending counts or alternate scene assumptions. Independent PR after #315; do not include in already-approved release.
## Cross-tab conflict safety
The form remembers the loaded profile values. A save refuses to overwrite a changed version of that same profile; unrelated profile edits remain independent. Users can copy the retained draft and explicitly reload saved values after confirmation. No automatic overwrite, deletion, or cross-profile progress migration. Pre-write checks without Web Locks remain best effort. Added two-tab browser and storage regression coverage.

## Playthrough navigation and Discovery backup protection — Nov 28
An explicit link opens the saved active journey in Discovery using a local-only URL fragment (opaque profile ID, no names/notes). Plain Discovery still begins unassigned. Switching a Discovery profile updates the fragment for reload; malformed or unavailable profile links block writes until an explicit selection. The journey link is hidden while edits are dirty or storage is blocked/busy. Discovery import refuses unsaved notes before reading the file. No storage migration, map/rotation changes, or inferred gameplay. Phone/desktop regressions cover actual link navigation, reload, unknown/malformed scopes and blocked import.
