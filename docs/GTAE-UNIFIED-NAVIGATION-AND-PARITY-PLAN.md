## One canonical hierarchy
Welcome (index.html): cinematic sign-in/guest gateway with sign-in honestly disabled until secure authentication is ready. Functional home (atlas-dashboard.html): choose game, resume progress, search. Direct home and map deep links never require a gateway or sign-in. Existing legacy URLs remain compatible; normal player navigation returns to functional home.
Game selection: GTA Online, GTA V Story, GTA VI Story, Classic GTA (IV + episodes, SA, VC, III, VCS, LCS, CTW); all 13 map destinations remain reachable, Cayo under Online.
Each game workspace offers consistent tabs: Map & legend, Activities/collectibles, Vehicles, Weapons, Characters, Guides; Heists/jobs and businesses only when applicable. Online daily/weekly is a first-class map legend and game overview function. Cayo and other local heists have their own maps.
My Garage -> atlas-forge-collections.html, with scoped garage management and approved customization workspace as children. My Armory is separate. Progress/backup and My Crew under My Stuff; no required sign-in.
Search: world + task + record; canonical results go directly to scoped record or map pin, not intermediary landing pages. Keep all legacy URLs/query links and stored IDs working. Retain a compact All Pages search, archive/advanced pages search-only by default.
Research: GTA VI unresolved evidence and map research only in a secondary section of the VI workspace. The released game is labeled GTA VI Story, not blanket Research. Keep Scaly/Yanis18, Loki/Dupzor51, in-game Day, Official, 2D/3D options, per-record uncertainty. No unverified feature claims. Technical data/style labs and credits separate from normal gameplay navigation. Sources & Credits canonical at atlas-credits.html; detailed attribution on that page, one compact visible license credit where required. Social links at the genuine page bottom; optional expansion on phones. No floating nonessential text over map controls.

## Acceptance and enforcement
One obvious entry per feature; no mandatory hop through dashboards. At 390px map controls never overlap footer, attribution or status; content can be scrolled to every control; menu closes and back returns to world; sharing only at document end. No duplicate full sharing grids. Source page contains detailed credits; legally required attribution remains visible and actionable. All 13 destinations and legacy deep links still resolve. Guest keys and per-world progress unchanged; no mandatory account. Unknown data never styled as verified. No replacement of approved artwork or private Forge exposure. Test changed journeys on both browsers as appropriate, reuse successful unaffected evidence and capture only affected visual pages. Native iPhone acceptance is not inferred from desktop viewport emulation. Freeze and promote through protected release gates; verify deployed SHA independently.
Use this plan as the shared backlog, not a second competing charter. Build in meaningful batches, verify each and record owner-visible improvements. Stop adding new overlapping hubs until navigation ownership and existing journey parity are clear.


## Player-first acceptance and competitive measurement
Follow the single active priority queue and competitive player-task benchmark in `docs/GTAE-UNIFICATION-BACKLOG.md`. Core features must work without manual data downloads, JSON imports, account setup or technical navigation. Measure actual anonymous player task outcomes on comparable devices and starting states against the strongest observed competing implementation, including correct game scope, interactions, time to usable result, freshness, coverage, saved progress and error/overlap rates. Separate unmeasured, source-described and independently exercised behavior. A successful test of a single game or mere HTTP availability is not sitewide acceptance. Improve the shared cause when a defect spans templates. Preserve all earlier accepted behaviors unless an owner-approved, tested replacement is better.
