# Team Jura Atlas Preview — Elario Studios

This package is designed to be uploaded to the **team-jura-atlas-preview** repository.

## Run locally

From the folder containing `index.html`, run `py -m http.server 8000` on Windows, then visit http://localhost:8000. Opening with `file://` can block local JSON fetches.

## Publish with GitHub Pages

Upload the **contents** of this ZIP to the repository root, commit to `main`, then Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save. Open the Pages URL once GitHub reports deployment.

## What is implemented

A new responsive Elario Studios/Team Jura Atlas landing page, searchable map directory, dedicated crew and studio pages, new visual styling, and preserved Atlas legacy tools and map engines from the previous development review ZIP. Existing reference gateways remain clearly labeled.

## What is not implemented

The 4K concept images are artwork, not a functioning UI. All older pages are preserved but not yet completely rebuilt as the new three-panel explorer. Public uploads, user accounts, shared progress, animated film, and AI cartoon studio are not live. Do not treat GTA VI provisional data as verified.

## Source and artwork policy

Keep existing attribution and research notes. Third-party game maps and artwork may require separate permission; MIT licensing of original code does not automatically cover those assets. The new concept images are creative artwork, not official Rockstar materials.
